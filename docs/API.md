# API Documentation

Base URL: `http://localhost:4000`

All protected endpoints require:

```http
Authorization: Bearer <jwt>
```

## Authentication

### POST `/api/auth/login`

```json
{
  "email": "admin@lela.sch.ke",
  "password": "Admin@123"
}
```

Returns a JWT and the authenticated user.

### GET `/api/auth/me`

Returns the current authenticated user.

Parent and student demo users include `linkedStudentId`; portal-facing module data is scoped to that linked student.

### GET `/api/auth/demo-users`

Returns demo users without passwords.

## Dashboard

### GET `/api/dashboard`

Returns school profile, role-visible modules, analytics metrics, quick actions, charts, notifications, and AI insight highlights.

## Modules

### GET `/api/modules`

Returns the modules visible to the signed-in role.

### GET `/api/announcements`

Returns role-visible announcements and notification items for the signed-in user.

### GET `/api/:module?q=<search>`

Supported module keys:

- `students`
- `teachers`
- `attendance`
- `academics`
- `timetable`
- `finance`
- `portal`
- `communications`
- `library`
- `inventory`
- `hostel`
- `transport`
- `aiInsights`
- `auditLogs`
- `backups`

The optional `q` parameter performs broad JSON-backed filtering in demo mode. In production, replace this with indexed database queries.

For `PARENT` and `STUDENT` roles, portal-sensitive data such as finance and portal records is scoped to the authenticated `linkedStudentId`.

## Writes

### POST `/api/students`

Roles: `ADMIN`, `PRINCIPAL`

Creates a student record and generates default student identifiers when missing.

### POST `/api/attendance`

Roles: `ADMIN`, `PRINCIPAL`, `TEACHER`, `ACCOUNTANT`, `LIBRARIAN`

Creates an attendance summary. QR mode can be marked with `qrEnabled: true`.

### POST `/api/finance/payments/mpesa/initiate`

Roles: `ADMIN`, `ACCOUNTANT`, `PARENT`

Accepts an M-Pesa-ready payment initiation request and returns a demo checkout request id.

### GET `/api/students/:studentId/report-card`

Roles: `ADMIN`, `PRINCIPAL`, `TEACHER`, `PARENT`, `STUDENT`

Downloads a compact PDF report card. Parent and student users can only download report cards linked to their portal account.

### GET `/api/finance/receipts/:receiptNo`

Roles: `ADMIN`, `PRINCIPAL`, `ACCOUNTANT`, `PARENT`, `STUDENT`

Downloads a compact PDF fee receipt. Parent and student users can only download receipts linked to their portal account.

## Finance

### GET `/api/finance/expenses`

Roles: `ADMIN`, `PRINCIPAL`, `ACCOUNTANT`

Returns expense records.

### GET `/api/finance/summary/balances`

Roles: `ADMIN`, `PRINCIPAL`, `ACCOUNTANT`

Returns billed, paid, outstanding, and collection rate totals.

## Search

### GET `/api/search?q=<query>`

Searches across the modules visible to the current role.

## Reports

### GET `/api/reports/:module?format=json`

Returns JSON report data.

### GET `/api/reports/:module?format=excel`

Returns a CSV file that opens in Excel.

### GET `/api/reports/:module?format=pdf`

Returns a compact PDF report generated by the API.

## Real-Time Events

### GET `/api/realtime?token=<jwt>`

Server-sent events stream for notifications and heartbeat events.

Events:

- `notification`
- `heartbeat`

## Health

### GET `/health`

Returns API status and timestamp.
